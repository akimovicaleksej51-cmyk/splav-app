# Сплав на iPhone через Sideloadly

Sideloadly — программа для Mac или Windows. Она ставит Сплав на iPhone с вашим Apple ID
и может сама продлевать подпись по Wi-Fi, пока компьютер включён.

Интерфейс Сплава обновляется сам, прямо в приложении. Переустанавливать через Sideloadly
нужно, только когда Сплав напишет «Новая основа Сплава» или «Подпись истекает».

## Один раз: подготовка

1. **Скачайте Sideloadly** с официального сайта https://sideloadly.io и установите.
   На Windows ещё нужен iTunes с сайта Apple (не из Microsoft Store).
2. **Скачайте Сплав**: файл `Splav.ipa` из последнего релиза «Сплав для iPhone»
   на странице https://github.com/akimovicaleksej51-cmyk/splav-app/releases
3. **Подключите iPhone кабелем**, разблокируйте и нажмите «Доверять этому компьютеру».
4. **Включите режим разработчика на iPhone**: «Настройки → Конфиденциальность и безопасность →
   Режим разработчика» → включить → перезагрузить → «Включить».

## Установка

1. Откройте Sideloadly. Вверху должен появиться ваш iPhone.
2. Перетащите `Splav.ipa` в окно Sideloadly (на значок IPA слева).
3. В поле **Apple account** впишите свой Apple ID и нажмите **Start**.
   Введите пароль от Apple ID, а если придёт код на телефон — его тоже.
4. Когда появится «Done», на iPhone откройте «Настройки → Основные → VPN и управление устройством»,
   выберите свой Apple ID и нажмите «Доверять».

Готово: Сплав на экране «Домой». Если раньше он был установлен через SideStore, входы в сервисы
могут сохраниться; если нет — войдите заново в профиле Сплава.

## Чтобы не продлевать руками каждую неделю

Бесплатная подпись Apple живёт 7 дней. Sideloadly умеет продлевать её сам по Wi-Fi:

1. Пока iPhone подключён кабелем, включите синхронизацию по Wi-Fi:
   - **Mac**: Finder → ваш iPhone слева → вкладка «Основные» → «Показывать этот iPhone, если он подключён к Wi-Fi» → «Применить».
   - **Windows**: iTunes → значок iPhone → «Обзор» → «Синхронизировать с этим iPhone по Wi-Fi» → «Применить».
2. В Sideloadly включите **AutoRefresh** (круглая кнопка внизу слева).

Теперь, если компьютер включён и iPhone в той же сети Wi-Fi, подпись продлевается сама.
Если не получилось — за 2 дня до конца подписи Сплав сам напомнит: подключите iPhone и нажмите
Start в Sideloadly ещё раз с тем же файлом.
